Maestro

AI-orchestrated multi-agent coding for Claude Code.

Maestro conducts a fleet of autonomous crews — plan, build, test, document, review, release — through your backlog, with human review gates where they matter. This is the distribution channel for the maestro CLI.

1 · Install

pip install --upgrade maestro --extra-index-url https://maestrodevs.github.io/simple/

2 · Activate your licence

mso licence activate <YOUR-KEY>

3 · Scaffold a project

From the repo you want Maestro to work in:

mso init --project YOURPROJ
mso status

Migrating from Admiralty? The admiralty package still installs as a backwards-compatible shim from the same channel — but new projects should use maestro.
