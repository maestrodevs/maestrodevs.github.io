# maestro-dist

Distribution channel for **Maestro** — AI-orchestrated multi-agent coding for Claude Code.

## Install

```bash
pip install --upgrade maestro --extra-index-url https://maestrodevs.github.io/simple/
```

This is a [PEP 503](https://peps.python.org/pep-0503/) simple repository index.
Wheels are published automatically by the `Admiralty` source repo's release workflow.

## Source

Code lives at https://github.com/tavisbasing/Admiralty (Maestro is the rebrand of the
Admiralty framework; the `maestro` package and `admiralty` shim ship from there).
